# Use one collection of earlier PRs to compare review strategies

For the new review comparison, direct search and convention learning will use the same dated collection of earlier PRs and review records. The automatic selector and the exact selector will use the same resulting catalogue. Only the offline exact selector and the evaluator can read the target's expert requests.

We chose this on 25 November 2026 because the existing search index lacks the earlier comment that introduced one of the two reference conventions for PR 42184. Using separate collections would change both the source evidence and its presentation. The choice of dates, eligible records and catalogue construction is still open.
