# The misses that no sampling reaches

**Status** — open, 2026-09-29, **for a fresh session**; a labelling study, no runs.
**Cost** — no spend.

**The user (2026-09-29).** *"The recall won't move beyond 0.5 much. The remaining issues haven't
moved in any runs. This points to them being a slightly different challenge, one which can't be
addressed effectively by more sampling."*

**Motivating examples.** Forcing the arms to speak took issue recall 0.20 to 0.50 on one rep with no
new investigation; the same set of obligations has been missed in every run since the held-out set
was cut. A distribution that never produces an ask does not produce it more often at three samples.
The fold search (`fold-search-2026-09-26`) reaches the "wrote out the body of a named concept" class
and nothing else; the closer battery reaches the mechanical asks; neither touches the design,
generality, twin and API-owed asks that recur among the misses.

**The hypothesis.** These asks are deltas between the PR and an alternative the reviewer constructs:
the shorter proof, the more general statement, the twin, the API a notion owes, the encoding the
area uses. They are absent from the model's output distribution because nothing in the input
prompts the construction, and they appear only when the input changes (an artifact, an area
regularity) or the task changes (construct, then compare).

**The study.** For each of the 38 misses of both sets, and for the variant-class design asks of the
validation and outside readings, label the artifact that would have exposed the ask: a usage of the
new API, a rewrite in the library's idiom, a generalisation attempt, a comparison with the area's
regularity, a reading of the whole PR, or none. Two readers, pre-registered vocabulary, counts by
family. The result decides which perspectives in `review-coordination-design.md` are worth
constructing and which conventions in `conventions-nature.md` they need.

**A starting point (2026-09-29).** One reader's pass and construction labels for the 38 misses and
the 31 sibling asks are in `results/pr_review_v5/adjudications/coordination-design-check-2026-09-29/`
(vocabulary: the constructions of `review-coordination-design-2026-09.md` §4). Planning labels, no
kappa; the two-reader study below supersedes them.

**What would close it.** The labelled table, and for the largest artifact class a demonstration on
three misses that constructing the artifact by hand exposes the ask, before any pipeline change.
