# Domain documentation

Use the [project glossary](../../GLOSSARY.md) for agreed terms and `docs/adr/` for design decisions. Consult relevant entries when they exist. Create an entry when a term or decision is settled. Use the agreed vocabulary in issues, code and reports.

Preserve the example that made a distinction matter. Identify whose judgment the rationale expresses. If new evidence changes a decision, link the earlier decision and explain what changed.
