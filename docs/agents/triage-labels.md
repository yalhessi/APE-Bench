# Triage labels

| GitHub label | When to use it |
| --- | --- |
| `needs-triage` | A maintainer needs to assess the issue. |
| `needs-info` | The reporter needs to supply more information. |
| `ready-for-agent` | An agent can complete the specified task independently. |
| `ready-for-human` | The work requires human implementation. |
| `wontfix` | The maintainer has decided to close the issue without pursuing it. |
