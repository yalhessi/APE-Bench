* `Complex.norm_deriv_le_div_of_mapsTo_ball`: if
  `f : ℂ → E` sends an open disk with center `c` and a positive radius `R₁` to a closed ball with
  center `f c` and radius `R₂`, then the norm of the derivative of `f` at `c` is at most
  the ratio `R₂ / R₁`;

* `Complex.dist_le_div_mul_dist_of_mapsTo_ball`: if `f : ℂ → E` sends an open disk with center `c`
  and radius `R₁` to a closed disk with center `f c` and radius `R₂`, then for any `z` in the former
  disk we have `dist (f z) (f c) ≤ (R₂ / R₁) * dist z c`;

* `Complex.norm_deriv_le_one_of_mapsTo_ball`: if `f : ℂ → E` maps an open disk with center `c`
  and a positive radius to the closed ball with center `f c` and the same radius,
  then the norm of the derivative of `f` at `c` is at most `1`;

* `Complex.dist_le_dist_of_mapsTo_ball_self`: if `f : ℂ → E` maps an open disk with center `c`
  to the closed ball with center `f c` and the same radius,
  then for any point `z` of this disk we have `dist (f z) (f c) ≤ dist z c`;

* `Complex.norm_le_norm_of_mapsTo_ball_self`: if `f : ℂ → E` sends `0` to `0` and an open disk
  with center `0` to the closed ball with center `0` and the same radius,
  then for any point `z` of this disk we have `‖f z‖ ≤ ‖z‖`.
