/-!
We have lots of lemmas describing how to simplify `colimit.ι F j ≫ _`,
and combined with `colimit.hom_ext` we rely on these lemmas for many calculations.

However, since `Category.assoc` is a `@[simp]` lemma, often expressions are
right associated, and it's hard to apply these lemmas about `colimit.ι`.

We thus use `reassoc` to define additional `@[simp]` lemmas, with an arbitrary extra morphism
(see `Mathlib/Tactic/CategoryTheory/Reassoc.lean`).
-/

/-- The coprojection `colimit.ι F j` followed by `colimit.desc F c` is `c.ι.app j`. -/
@[reassoc (attr := simp)]
theorem colimit.ι_desc {F : J ⥤ C} [HasColimit F] (c : Cocone F) (j : J) :
    colimit.ι F j ≫ colimit.desc F c = c.ι.app j :=
  IsColimit.fac _ c j
