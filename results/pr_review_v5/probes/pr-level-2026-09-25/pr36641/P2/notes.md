# PR #36641 — reviewer notes (PR as a whole)

1. **Wanted / worth having.** A real Ville (maximal) inequality for nonnegative supermartingales would be wanted, and `maximal_ineq` exists only for submartingales (OptionalStopping.lean:157). The PR does not deliver it: its headline result is the fixed-n bound from Markov plus monotone expectation. `measureReal_le_div_forall` is an eta-expansion of that result. `integral_le` is `setIntegral_le` at univ (Basic.lean:153). Filed as blocking (not Ville; trivial ∀ wrapper).
2. **Every hunk an improvement.** Both hunks are additions: the new file, and a correctly alphabetised `Mathlib.lean` import. There are no stylistic edits to existing code and nothing unrelated to revert.
3. **One thing.** Scope is a single topic. The exception is `integral_stoppedValue_le`, which nothing in the PR uses (it is the ingredient the missing maximal proof needs). This is covered under findings Q1/Q6 rather than as a split request.
4. **Description.** It is empty: no motivation, no design rationale (μ.real/ℝ versus the ENNReal/ℝ≥0 form of `maximal_ineq`), no links, and a truncated title. The header credits only "AI Math Project", with no human author and no AI disclosure. Filed as two blocking findings.
5. **Finishes the job.** `Supermartingale.integral_le` has no counterpart for sub/martingales. There is no general `Supermartingale.expected_stoppedValue_mono` (τ ≤ π), only the τ = 0 case. These are folded into the Q6 findings as requested additions. There is no automation or meta code, so no tests are needed.
6. **Right place.** `integral_le` belongs in Martingale/Basic.lean beside `setIntegral_le`. The stopped-value lemma and any maximal Ville statement belong in OptionalStopping.lean (next to `expected_stoppedValue_mono`, and in the `Maximal` section), not in a new file. That file has no supermartingale results today (mlcount = 0). Filed as two advisory findings.
